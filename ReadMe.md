# About

Cybersecurity student in the USA. I build crypto scam intelligence tools, security monitoring, and AI agent tooling.

# Security research

Two published GitHub security advisories, both as reporter:

- [imapflow](https://github.com/postalsys/imapflow/security/advisories/GHSA-g78f-3cr8-fhw5): a hostile IMAP server could force unbounded memory allocation (medium).
- [@asamuzakjp/css-color](https://github.com/asamuzaK/cssColor/security/advisories/GHSA-6g4c-jm42-jc5r): a deeply nested `color-mix()` crashed the parser (medium).

# Featured projects

- [nethersec](https://github.com/netherportal3/nethersec): self-hosted security monitoring for Linux servers, a Windows PC and GitHub repos, with Discord alerts.
- [claude-campaign](https://github.com/netherportal3/claude-campaign): a Claude Code skill that runs a large multi-part coding job unattended as phases of agents.
- [discord-cve-monitor](https://github.com/netherportal3/discord-cve-monitor): watches repo lockfiles for known vulnerabilities. Archived, succeeded by nethersec.
- [led-sign-studio](https://github.com/netherportal3/led-sign-studio): draw, animate and run a weather and news display on cheap Bluetooth LED signs from Windows.
- [sellauth-nowpayments-integration](https://github.com/netherportal3/sellauth-nowpayments-integration): accept crypto payments through NOWPayments on SellAuth's manual checkout.
